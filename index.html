Synthèse scolaire personnelle

Cette application à usage personnel prépare une synthèse en français d’informations scolaires consultées dans un espace parent Pronote autorisé, puis l’envoie par Gmail au titulaire du compte.

Elle regroupe les sept jours précédents, la journée en cours et les sept jours suivants. Le traitement applique des règles de dates et de présentation, sans service supplémentaire d’intelligence artificielle.

Ce service privé n’est ni un service officiel de Pronote, ni une application proposée à l’inscription du public.

Règles de confidentialité

Règles de confidentialité

Mise à jour : 18 septembre 2026.

Données utilisées et finalité

L’application utilise les informations scolaires accessibles au compte parent autorisé : devoirs, évaluations, notes, événements signalés dans l’emploi du temps, éléments de vie scolaire disponibles, annonces et discussions concernant l’élève. Ces données servent uniquement à préparer et envoyer la synthèse personnelle demandée. Les discussions sont consultées sans réponse automatique ni modification de leur statut de lecture.

Autorisation Google

L’unique autorisation Google demandée est l’envoi de messages avec Gmail (gmail.send). L’application utilise cette autorisation pour envoyer la synthèse depuis le compte autorisé vers ce même compte. Elle ne demande pas d’accès à la lecture de la boîte de réception, aux contacts ou aux fichiers Google Drive.

Traitement, stockage et destinataires

Le programme s’exécute dans GitHub Actions au sein d’un dépôt privé. Les identifiants Pronote et le jeton Google renouvelable sont conservés dans les secrets chiffrés du dépôt. Les données scolaires sont traitées pendant l’exécution ; elles ne sont pas publiées dans le dépôt, les journaux ou les artefacts GitHub. Un registre privé conserve uniquement les dates, statuts et identifiants techniques nécessaires pour prévenir les doublons.

Google traite et conserve les courriels dans Gmail selon les réglages du titulaire. Le destinataire prévu est le titulaire du compte. Les données ne sont ni vendues, ni utilisées à des fins publicitaires ou d’entraînement d’un modèle d’intelligence artificielle.

Contrôle et suppression

Le titulaire peut désactiver les envois dans GitHub Actions, supprimer les secrets et le registre privé, effacer les messages dans Gmail et révoquer l’autorisation dans les connexions de son compte Google. L’adresse d’assistance du titulaire est indiquée sur l’écran de consentement Google.

Usage des données Google

L’utilisation des informations reçues des API Google respecte la Google API Services User Data Policy, y compris les exigences de Limited Use.

Cette page publique

Cette page décrit le fonctionnement du service. Elle ne contient aucune donnée scolaire, aucun nom d’élève et aucun identifiant de connexion. Elle n’intègre ni formulaire de collecte, ni outil de suivi publicitaire.
